## 👨‍💻 Tentang Kami

Kami adalah siswa **Rekayasa Perangkat Lunak (RPL)** dari **SMKN 7 Batam**
yang sedang membangun berbagai project sebagai bagian dari pembelajaran dan pengembangan skill di dunia teknologi.

Organisasi ini dibuat untuk:

* Menyimpan seluruh project siswa dalam satu tempat
* Melatih penggunaan Git & GitHub secara profesional
* Membangun portofolio digital
* Belajar kolaborasi seperti tim developer sungguhan

---

## 🧠 Mindset Kami

## 📦 Struktur Repository

Setiap siswa memiliki repository masing-masing dengan format:

```bash
[NAMA_LENGKAP]-[JUDUL_PROJECT]
```
Contoh : SHASWAN_KHAN-PENGADUAN_SARANA_SEKOLAH

---

## 📋 Standar Project

Setiap repository WAJIB memiliki:

* 📄 README.md (penjelasan project)
* ⚙️ Cara instalasi & penggunaan
* 🧾 Deskripsi fitur
* 👤 Identitas pembuat (nama & kelas)

---

## 💬 Diskusi & Bantuan

Gunakan fitur **Issues** untuk:

* Bertanya jika mengalami kendala
* Diskusi teknis
* Melaporkan bug atau error
